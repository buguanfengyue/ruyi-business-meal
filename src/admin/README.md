# 商户后台（电脑端）

按原商户后台的页面布局与跳转复刻，代码为自写的 React 实现（未复制原平台源码或素材）。

- 第一期：全部页面与跳转（`mock.js` 演示数据）。
- 第二期（当前）：核心经营页面已接入本项目后端 `/api/admin/*`；后端尚未支持的功能页面保留演示数据，页面顶部显示灰色“演示数据”标签。

## 运行

```bash
npm run api   # 读取 .env，首次启动按 ADMIN_USERNAME/ADMIN_PASSWORD 创建管理员
npm run dev
# 浏览器打开 http://127.0.0.1:5173/admin.html ，用 .env 里的管理员账号登录
```

本地 `.env`（已被 git 忽略）里有开发用管理员账号；修改密码：`npm run admin:password -- boss`，或登录后在右上角门店菜单里“修改密码”。

生产构建 `npm run build` 会同时输出 `dist/index.html`（顾客端 Web）和 `dist/admin.html`（商户后台）。

## 结构

| 文件 | 内容 |
| --- | --- |
| `main.jsx` | 路由表（地址与原后台一致，如 `#/order/list`）、登录拦截、面包屑 |
| `menu.js` | 左侧 13 个一级入口及子菜单 |
| `Layout.jsx` | 图标侧栏（悬停浮层/提示）、☰ 展开菜单、顶栏面包屑与门店下拉 |
| `ui.jsx` | 通用组件：按钮、表单、表格（多列右侧固定）、分页、标签页、弹窗、环形图、提示 |
| `pages/data.jsx` | 数据分析（首页）、销售汇总、营业报表、桌台统计、余额统计、提成统计 |
| `pages/tools.jsx` | 收银管理、桌台管理、代客下单、挂账管理、交接班 |
| `pages/goods.jsx` | 分类设置、商品列表、添加/编辑商品、库存预警、规格模板、必点商品、进销存、标签管理、单位管理 |
| `pages/orders.jsx` | 订单列表、用户列表 |
| `pages/setting.jsx` | 小程序管理、门店设置(3 个标签)、订单提醒、小程序助手、界面设置、系统设置、第三方配送、打印机设置、桌码生成、大屏幕管理、开发配置 |
| `pages/assist.jsx` | 客服设置、物流助手、订单来源码、生成小程序码 / Short Link / Url Link、外部业务域名 |
| `pages/misc.jsx` | 微信支付品牌、轮播广告、营销管理(含优惠券/智慧充值/超级会员/共享模式及通用营销页)、应用中心、员工管理、设备、登录页 |
| `mock.js` | 全部演示数据（顾客信息均为虚构） |

## 接入状态

| 已接入真实数据 | 说明 |
| --- | --- |
| 登录 / 退出 / 修改密码 | `POST /api/admin/login` 等，登录失效自动回到登录页 |
| 首页数据统计 | 今天/昨天/本周/本月/上个月/自定义；营业实收、支付顾客、会员占比、人均、按配送方式与支付方式拆分 |
| 销售汇总、营业报表 | 按商品、按营业日统计；报表只显示本系统有数据的列（可切换显示全部列） |
| 订单列表 | 搜索（订单号/取餐号/商品/手机号）、日期、状态标签与数量、汇总、接单、出餐完成、取消并退款、重试退款、详情（含支付记录）、导出 CSV、自动刷新 |
| 新订单提醒 | 每 15 秒检查待接单订单，有新单时提示音 + 弹窗 + 左侧红点；在 配置管理 → 订单提醒 可关闭声音 |
| 商品列表、添加/编辑商品、分类设置、库存预警 | 增删改、上下架（单个/批量）；商品图片暂用表情图标，待接入对象存储 |
| 用户列表 | 搜索与筛选、统计、顾客详情（订单/优惠券）、单个/批量发券 |
| 门店设置 | 名称、电话、营业状态（暂停接单）、营业时间、公告 |
| 会员（超级会员） | 会员等级门槛、折扣、等级说明、积分规则 |
| 满减优惠券 / 邀请裂变 | 优惠券发放与使用统计；邀新奖励券（新用户/邀请人）设置 |
| 共享模式 | 佣金比例、合伙人页面说明 |
| 开发配置 / 员工管理 | 立即备份数据库；操作日志 |

仍为演示数据（后端尚未支持对应业务）：收银、桌台、代客下单、挂账、交接班、进销存、规格/标签/单位/必点、余额与提成统计、员工账号与权限、界面装修、系统设置、第三方配送、打印机、桌码、大屏幕、轮播广告、应用中心、辅助功能、微信支付品牌，以及其余营销活动。需要哪一项，先补后端再接页面。

接口封装在 `api.js`（统一带 token、401 处理、CSV 下载）；页面里仍调用 `pending('…')` 的按钮即尚未接入的操作。
